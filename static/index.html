SpamShield

Paste an SMS. A TF-IDF logistic regression and a fine-tuned MiniLM transformer each score it, then you can see how easily a spammer's formatting tricks change the scores.

Obfuscation probe

Re-scores your message with leetspeak, look-alike letters, dotted words and link tricks.

Trained on the 2011 English UCI SMS Spam Collection (5,159 de-duplicated messages). It is a benchmark model, not a production filter: it has not been tested on current scams, other languages or Indian SMS traffic. Messages are scored in memory and not stored.
